IgrejaFy — Setup & Installation Guide

Clean setup and deployment documentation for new Windows machines

Production Ready
Updated: October 2026
1
Configure PHP Extensions (php.ini)

On a fresh Windows PHP installation (e.g., C:\php\php.ini), several required extensions are disabled by default. Remove the leading semicolon (;) from these directives:

extension_dir = "ext"
extension=fileinfo
extension=pdo_mysql
extension=mysqli
extension=zip
  • fileinfo: Mandatory for Composer packages such as league/flysystem.
  • pdo_mysql & mysqli: Required for Laravel database connection to MySQL.
  • zip: Allows Composer to quickly extract vendor zip packages.
2
Install PHP Dependencies

Open PowerShell or Command Prompt in the project folder and download the vendor packages:

# For local development:
composer install

# For production deployments:
composer install --no-dev --optimize-autoloader
3
Database Setup & .env Configuration

A. Create the MySQL Database:

CREATE DATABASE IF NOT EXISTS igrejafy CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;

B. Configure credentials in .env:

DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=igrejafy
DB_USERNAME=root
DB_PASSWORD="your_password"

Crucial Gotcha — Passwords with '#'

If your database password contains special characters (especially #), you MUST wrap it in quotes (e.g. DB_PASSWORD="Gguihelo1990#"). Without quotes, phpdotenv treats # as an inline comment and clips your password, causing Access denied for user 'root'@'localhost' (1045).

4
Generate Application Key & Run Migrations

Initialize Laravel's cryptographic key and create all database tables:

# 1. Generate key
php artisan key:generate

# 2. Run migrations
php artisan migrate

All database tables (users, cache, jobs, people, baptisms, visits, etc.) will be created.

5
Frontend Dependencies & Asset Compilation

To prevent the error 'vite' is not recognized as an internal or external command, install Node packages:

# 1. Install frontend packages (Vite, Tailwind, Bootstrap, etc.)
npm install

# 2. Build assets for production (generates public/build/manifest.json)
npm run build

Production Tip

Once npm run build is executed, the compiled CSS and JS are saved in public/build. You do not need to keep npm run dev running in production.

Quick Checklist for Future Machine Installations

# 1. PHP setup: Enable fileinfo, pdo_mysql, mysqli, zip in C:\php\php.ini
# 2. Install dependencies:
composer install
# 3. Environment: Copy .env.example to .env (if fresh clone) and configure DB
# 4. MySQL: CREATE DATABASE igrejafy;
# 5. Initialize application:
php artisan key:generate
php artisan migrate
npm install
npm run build
# 6. Run server:
php artisan serve
